## Installation
```bash
git clone https://github.com/itriedcoding/advanced-osint-tool.git
cd advanced-osint-tool
```

Double-click `run_osint.bat` or run:
```bash
python osint_tool.py
```

## Setup
1. Get free API keys:
   - HaveIBeenPwned: https://haveibeenpwned.com/API/Key
   - Optional: Shodan, etc.

2. Place keys in `config.py` (will be auto-created on first run)
